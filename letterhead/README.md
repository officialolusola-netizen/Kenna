## 🚀 Quick Start

### Method 1: Using Your Logo Image

1. Save your new circular logo as `assets/new-logo.png` in the letterhead directory
2. Open `letterhead.html` in a text editor
3. Find the logo placeholder section (around line 172):
   ```html
   <div class="logo-placeholder">
       <!-- Replace this div with your logo image -->
       <!-- <img src="assets/new-logo.png" alt="The Intellingentsia Nigeria Logo"> -->
   ```
4. Uncomment the `<img>` tag and comment out or remove the placeholder div
5. Save the file

### Method 2: Quick Preview

1. Open `letterhead.html` directly in your web browser
2. The design includes a placeholder that shows where your logo will appear
3. Replace the placeholder with your actual logo when ready

## 📄 Using the Letterhead

### For Digital Documents

1. Open `letterhead.html` in your web browser
2. Edit the content section with your letter text
3. Save the file
4. Open in browser and use "Print to PDF" to create a PDF document

### For Microsoft Word

1. Open the letterhead in a browser
2. Print to PDF
3. Insert the PDF as a background/header in Microsoft Word
4. Create your Word template

### For Multiple Letters

1. Use `letterhead-blank.html` (template without sample content)
2. Copy and customize for each letter
3. Or create a script to populate content dynamically

## 🔧 Troubleshooting

### Logo not appearing?
- Check that the image path is correct
- Ensure the logo file is in the `assets/` folder
- Verify the image format is supported (PNG, JPG, SVG)

### Print layout issues?
- Use "Print to PDF" instead of physical printing first
- Check page margins are set to "None" or "Minimum"
- Ensure "Background graphics" is enabled in print settings

### Fonts not loading?
- Requires internet connection for Google Fonts
- For offline use, download fonts and link locally

## 💡 Best Practices

1. **Logo Quality**: Use a high-resolution logo (at least 500×500px) for crisp printing
2. **Content Length**: Keep letters to one page when possible for professional appearance
3. **PDF Export**: Always create a PDF version for official correspondence
4. **Consistency**: Use the same letterhead version across all official documents
5. **Backup**: Keep master copies of customized letterheads
